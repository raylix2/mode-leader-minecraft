# Publication sur GitHub

Ce dossier est prêt à être publié dans un dépôt nommé `UniversalServerLoader`.

## Dépôt

1. Créez un dépôt GitHub public vide nommé `UniversalServerLoader`.
2. Importez tout le contenu de ce dossier, sauf le sous-dossier `_RELEASES`.
3. Utilisez `main` comme branche principale.
4. Description conseillée : `Lanceur et superviseur local pour serveurs Minecraft Paper, avec interface graphique et API d’addons.`

## Release

1. Créez un tag et une release `v0.3.8`.
2. Titre conseillé : `UniversalServerLoader 0.3.8`.
3. Utilisez la section `0.3.8` de `CHANGELOG.md` comme notes de version.
4. Ajoutez `_RELEASES/UniversalServerLoader-0.3.8.zip` comme fichier téléchargeable.

SHA-256 de l’archive :

```text
13984C7C5ECC4899C56F9F768915AA34CFAA22DBE0F0016ED4F03FA657D6448D
```

Le serveur Minecraft, Paper, les mondes, les logs et les données de joueurs ne sont pas inclus.

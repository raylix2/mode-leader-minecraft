# Politique de sécurité

Merci de ne pas publier publiquement un rapport contenant une vulnérabilité exploitable, des identifiants, des mondes privés ou des journaux serveur sensibles.

Pour un rapport, ouvrez une alerte de sécurité privée GitHub lorsque cette fonction est disponible sur le dépôt. Indiquez la version concernée, les étapes minimales de reproduction et l’impact observé.

Les fichiers `server.jar`, les plugins et les mods tiers ne font pas partie du périmètre de maintenance d’UniversalServerLoader.

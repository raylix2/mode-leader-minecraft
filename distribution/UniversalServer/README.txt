UNIVERSAL SERVER LOADER 0.3.8

1. Placez votre serveur Paper 1.21.11 dans ce dossier sous le nom server.jar.
2. Installez Java 21.
3. Lancez start.bat sous Windows ou start.sh sous Linux/macOS.
4. Lisez l'EULA Minecraft et acceptez-la uniquement si vous êtes d'accord.
5. Cliquez sur Démarrer.

Le serveur, Paper, les plugins et les mods tiers ne sont pas inclus.
